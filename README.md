## Key Features

- **Centered & Clean Light Layout**: High-contrast, elegant card presentation built without dark mode clutter or fabricated metrics.
- **Three Actions per App**:
  - **Learn More**: Full-screen modal deep dive detailing the problem/solution, core functions, end-user ROI metrics, and whitelabel business model.
  - **Tech Stack**: Deep architecture modal highlighting why the application is durable, fault-tolerant, and continuously evolving.
  - **Launch App**: Direct link opening the live production instance in a new tab.
- **Whitelabel Licensing Inquiries**: Integrated modal routing requests with licensing tier selection and lead attribution directly to paljuritzen@gmail.com.
- **Zero Heavy Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript. No complex build step required; instantly deployable on GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

## BizBox Licensing Framework

- **Tier 1: Non-Exclusive Turnkey Whitelabel** — Custom brand, custom domain, keep 100% end-user client MRR. Managed cloud hosting & AI upgrades.
- **Tier 2: Lease-to-Own License** — Low upfront capital with 70% of monthly payments credited toward full buyout.
- **Tier 3: Master Buyout & IP Transfer** — Complete GitHub repository source code and intellectual property transfer with unlimited sub-licensing rights.
